# 决策：本 fork 的新增能力默认开启

状态：当前有效。范围：会话、关闭确认、回滚缓存、窗格标题栏、浮层最大化、自动字号、备用屏幕滚动条。

## 问题与约束

上游 Terminator 不会在普通启动时恢复上次的窗口和目录。这个 fork 加上了会话、回滚缓存、窗格标题栏、浮层最大化和按阅读宽度缩放字号。若默认关闭，用户每次都要自己发现开关，和「打开就能接着用」的目标相反。

## 决定与理由

上述能力默认开启。每一项都可以在首选项或配置里单独关闭，单次启动还可以用 `--no-restore`。

曾考虑默认关闭、由用户显式打开。那样升级更安静，但本 fork 的使用者要的就是这些行为，所以不采用。

回滚缓存写在本机缓存目录，权限收紧到用户自己可读写。不做敏感命令排除列表，因为目标是私人机器。

## 影响与退出条件

升级上来的人会立刻看到这些行为。不想要的人关掉对应的键即可，键名在 `man terminator_config`。若以后要做一个「尽量像上游」的兼容模式，应新增开关，而不是把现在的默认值改回去。

## 现行约束与入口

需求见 [TX-01 至 TX-07](../requirements/terminatorx.md)。原则见 [产品原则](../principles/product.md)。默认值的代码在 `terminatorlib/config.py`。
